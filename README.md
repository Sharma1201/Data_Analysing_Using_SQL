# Retails Dataset SQL Analysis

This project contains SQL queries and outputs for analyzing a retail database.

## Dataset
The dataset is stored in the **Retails_dataset** folder and contains three tables:
- **customer_profiles** – Customer details (CustomerID, Age, Gender, Location, JoinDate)
- **product_inventory** – Product details (ProductID, ProductName, Category, StockLevel, Price)
- **sales_transactions** – Sales details (TransactionID, CustomerID, ProductID, QuantityPurchased, TransactionDate, Price)

## Files
- **Retails_dataset** - Contain Dataset Used
- **retails_dataset_Task4.sql** – Contains all SQL queries
- **SQL_Queries_Output_Screenshot.pdf** – Screenshots of query outputs

## Tasks Performed
- Data selection using `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
- Used aggregate functions: `SUM`, `AVG`, `MIN`, `MAX`
- Performed joins: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `SELF JOIN`
- Wrote subqueries for filtering and comparisons
- Created views for reusable analysis
- Created indexes to optimize filtering and joins

## Outputs
All results and screenshots are provided in the PDF file.
